# Frame One v0.13A14 — Ten authentic visual filmmaking lessons

## What this milestone changes

Expand the existing **Show → Compare → Notice → Explain → Try** film notebook from
six original A/B studies to **16** studies, alongside the three progressive
scene sequences built previously. This gives **19 of the 33 existing lessons**
a visual-first entry point, without deleting or replacing their original text,
quizzes, Telugu helpers, practice notes or completion routes.

Unlike a generic infographic, all ten new lessons have individual original,
offline SVG illustrations in `TenVisualFrames`, with meaningful visual
differences tied to the lesson's actual filmmaking point. Ten authored
editorial studies live in `visual-choice-ten.ts`. A learner chooses between
two views, examines a short observation, expands the filmmaking rationale
only on request, and opens an actual existing Creative Lab.

| Lesson | Interactive experiment | Truthfulness constraint |
|---|---|---|
| Story | Missing key vs important thing it opens | Stakes depend on context |
| Screenplay | Unfilmable internal emotion vs visible hiding action | Examples, not rigid industry script format |
| Acting | Same line, open posture vs guarded posture | Static pose, no voice/audio |
| Character | Open door vs locked door/obstacle | No correct creative outcome assumed |
| Dialogue | Same “I'm fine”, eye contact vs averted gaze and action | No universal emotional interpretation |
| Camera | Eye-level view vs low-angle illustration | Simplified perspective, not optical simulation |
| Movement | Pan from one point vs camera translating | Top-down paths, not moving video |
| Lenses | Same position crop vs changed camera position | Simplified geometry; perspective determined by position |
| Music | Same locked room with two **written imaginary** score ideas | No music played, recorded or falsely promised |
| Editing | Same three shots, wide-first vs cup-first | Shot reveal order, not playback |

The feature uses no third-party movie stills, generated media dependencies,
remote APIs, camera permission, account, extra localStorage keys, or paid tier.
The original seven Labs are linked from the ten lesson cards and remain
independently usable.

## QA acceptance

- Source tests: 16 real A/B lessons, original legacy six illustrations,
  all ten new authored titles, original distinct SVG compositions, truthful
  fixed-picture Music directions, no state-storage changes and original quiz.
- Browser tests on actual compiled production site: each of the ten lessons
  must open from offline Home search; A/B switch must change SVG imagery
  (except Music, where the artwork must remain identical); optional reasoning
  and original quiz/practice-note controls must be accessible; screenshot for
  every lesson.
- All ten additions receive phone layout/overflow tests, divided between
  390px and 320px real Chromium viewport environments, plus screenshots.
- Existing full app suite, accessibility interactions, lessons, seven Labs,
  offline behavior, backup state and debug Android build continue in CI.

## Distribution boundary

The v0.13A14 APK produced by GitHub CI is **temporarily debug signed** and
should be treated as an independent fresh-install test build. It is *not*
a proven safe update over any existing installed version. Do not uninstall
an installation containing saved data unless a backup has been exported
and independently verified. Public managed preview stays **v0.12A2** until
the long-lived signer and real-phone update checks have been established.
