# Frame One v0.15A6 — Crew Decision Studio

## Purpose
The existing film-craft introduction contains nine role cards and a four-stage crew map. Add a practical, visual, **optional** exercise on the Meet Film Roles screen rather than increasing copy or cards on the Home screen.

## Experience
Three original, shootable production challenges: a reaction hidden against a window, a dialogue line masked by traffic, and a reaction cut away too soon. The reader chooses which role to consult: direction, cinematography and lighting, location sound, or editing. The original film-set SVG highlights the selected department, a specific contribution appears, and a short collaboration note explains why no single craft works alone.

## Safety and accuracy
- Uses the same real roles already taught on the nine-card page. No fabricated universal hierarchy or claims that '24 crafts' is a worldwide standardized list.
- Keeps all three situations and role notes accessible offline; user selections are session-only.
- The original SVG is an illustration, not film footage or a camera simulation; diagram has a descriptive accessible name.
- New section is collapsed by default. Learners choose to open; no extra home surface.
- Does not edit any of the 33 lesson records, seven labs, local projects, storage keys, permissions or backup formats.
- 320px/390px responsive layout, accessible button labels, pressed state and visible keyboard focus.

## QA
Add a standalone source guard and real Chromium desktop/mobile checks: default closed panel, three scenarios, role selection, live illustration state, reset on scenario change, absence of horizontal overflow. Require existing web production build, browser tests, Android debug/emulator and both upgrade-preservation pipelines green before merge. Public app APK signing remains separate.
