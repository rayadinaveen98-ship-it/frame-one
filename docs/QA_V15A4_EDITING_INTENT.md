# Frame One v0.15A4 — Editing Intention Workshop

Three short optional prompts inside the existing **Cut Lab**: introduce the location, make a clock feel meaningful, and begin with a character. Learners experiment with real existing shot order and hold durations. A non-scoring discussion reacts to opening shot, opening hold time, closing shot and total time. It contrasts the six-second default storyboard with their current three-shot edit.

- Workshop is closed by default and has no additional Home card.
- Suggested edits are optional and modify the **actual** React-owned Cut timeline. Applying one stops existing playback, returns to the first frame and replaces the current temporary edit; it never runs an extra animation.
- No persistence, account, new media, API requests or changes to the existing 33 lessons, seven labs, learner notes, film projects, backup format or signing identity.
- The exercise is honest about the limited illustrated materials: no recorded actors, real scene footage, emotional prediction or assessment score.
- Keyboard focus, 44px minimum action targets and 320/390px responsive layout are required.
