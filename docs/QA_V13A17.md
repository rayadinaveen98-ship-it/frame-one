# Frame One v0.13A17 — A clear path through every lesson

## The problem

All 33 lessons start visually, but the reader still has a scene study,
an optional creative decision, deeper reading, their notes and a knowledge
check. There was no way to jump between these blocks. This milestone improves
the lesson experience without adding more oversized Home cards.

## UI implemented

- A quiet three-button strip beneath the lesson title:
  **01 Explore** / **02 Decide** / **03 Check**.
- Each button moves to its real section, explicitly focuses the target
  for keyboard/screen-reader navigation and honors reduced-motion settings.
- Explore opens the original visual, Decide reaches the creative dilemma,
  and Check moves to the original knowledge quiz.
- A wrong answer now offers optional **Review the visual scene**. It
  returns the learner to the original illustration without resetting the
  quiz, awarding completion or adding a progress tracker.
- The original Try again and answer-gated Mark lesson complete buttons
  remain unchanged.

## Safety and compatibility

Original 33 lessons, 6 chapters, seven creative Labs, glossary, roles,
Telugu summaries, personal gallery, saved practice notes, backup JSON schema,
film-journey navigation, completed states and progress keys remain the same.
The guide is navigation only, not a completion or activity tracker.

## QA

- Source contract verifies real anchors, screen-reader labels, focus,
  reduced-motion, wrong-answer review and untouched progress routing.
- Desktop Chromium checks all three jumps and wrong-answer review/try-again
  on a real published lesson.
- Phone Chromium tests 320px/390px widths, no horizontal overflow,
  navigation focus and screenshots.
- Full web TypeScript/Vite/offline suite, original seven Labs, backup/route
  regressions and Android debug packaging must pass before merge.

## Android boundary

Debug builds may be temporarily signed. This test APK cannot be assumed
to update an older installed package without a verified matching
certificate. The managed public preview remains v0.12A2 until persistent
signing and real-phone upgrade/backup acceptance.
