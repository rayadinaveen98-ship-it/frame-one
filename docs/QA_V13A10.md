# Frame One v0.13A10 — Pocket Shoot Plan

## What the learner can do

The existing **Film It Yourself** desk now includes a collapsible
**Pocket shoot plan** for each of the four real exercises.

1. Select an exercise and optionally tick its shooting steps.
2. Choose **Prepare my plan** to see a plain-text copy of its three steps,
   the reason each shot matters, an after-filming reflection question and
   the basic safety reminder.
3. Optionally write up to 240 characters about the two takes or what changed.
4. Select **Copy the full shot plan** to send it to Notes/a trusted app.
   When Android/WebView/browser clipboard access is not available, the
   interface explicitly says copying failed and selects a visible,
   read-only text area for manual copying. It never falsely claims success.

Notes are **not autosaved**, backed up, uploaded, scored or shared.
Leaving the page or changing exercise clears the temporary reflection.
The user must copy the guide to retain it. All guide text is taken from
the existing offline course; no accounts, permissions, service fees or
network access are needed.

## Safety and compatibility

This extends the existing practical workshop rather than modifying
completion state, the 33 lessons, Make Lab's one saved storyboard,
personal slideshow, local progress schema or backup JSON. No app-storage
keys or native plugins were added. Camera footage is never captured,
read or inspected by this feature.

## Automated acceptance

- Source verification checks four complete three-step guides,
  deterministic formatting, a bounded 240-character reflection, no
  missing lesson text, local-only execution and the selectable copy
  fallback.
- Real Chromium browser smoke covers opening the plan, editing an
  observation, trying clipboard copy, and ensuring the exercise switch
  does **not** retain the previous note.
- 320px and 390px real-browser phone layouts verify no horizontal
  clipping and provide screenshots for the expanded pocket plan.
- Existing website TypeScript/build, original lessons, labs, navigation,
  backup and emulator tests stay enabled.

## Android test-package boundary

This milestone can produce a **temporary-signed test APK** in GitHub
Actions, but this is NOT an in-place-upgrade-safe public release.
The latest public downloadable APK stays v0.12A2 until private
persistent QA signing, separate-build acceptance and real-phone
upgrade/backup checks are complete. If the signed test APK is
provided directly, testers must use a fresh install/test profile,
or first export and independently verify their backup before any
reinstallation that could erase data.
