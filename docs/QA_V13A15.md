# Frame One v0.13A15 — Visual-first coverage of all 33 lessons

## Result
This phase converts the **final fourteen existing curriculum lessons** into
original illustrated learning experiences. Together with 16 earlier A/B film
studies and 3 earlier progressive scene exercises, **all 33** now *begin*
with a visual-first teaching experience. This does not claim that every
original paragraph has been rewritten or that all examples are moving video.

The new **Visual Field Guide** format shows a unique 16:9 offline original
illustration at each of three stages. The student steps through the
visual, reads one concrete observation, and can reveal filmmaking
reasoning after the final stage. It includes a one-sentence takeaway
and a real-world phone task and links to the *existing* seven Creative Labs.
The long original text, optional Telugu summary, old storyboards and
comprehension quiz remain available in their original lesson route.
Progress is never awarded by tapping through the three illustrations.

## New lesson / what changes visually

| Existing lesson | Three designed scenes |
|---|---|
| Why watch films? | Person waits → empty chair becomes a question → clock gives a time cue |
| Cinema history | Sequential-image viewing experiment → projector and screening → film-strip storytelling |
| Genres | Lost phone → potential comic pocket reveal → imagined mystery message |
| Indian cinema | 1896 screenings → disputed 1912/1913 early-feature milestones → many languages |
| Sound | Locked illustrated room → outside sound rings → phone ring directs attention |
| Film crew | Set and props → performer, camera and lighting → assembly and sound finish |
| Telugu “24 crafts” | Industry expression → examples of worker tasks → different crew sizes |
| Department teamwork | Writer's page → staged prop/performer → finished edit with sound |
| Pipeline | Plan → record → finish and share; overlapping production stages explained |
| First film | Write one small scene → film on a phone → cut a first sequence |
| Shot list | Three shot-plan rows; wide, action and insert focus update |
| Shoot a phone scene | Permission/checklist → recording → review before leaving |
| Edit minute | Raw recorded frames → select → review sound joins |
| Review your film | Show a cut → ask focused questions → revise one craft choice |

The artwork is original SVG from the project, not archival video, music,
licensed film stills, playable sound, a built-in camera, or a physically
accurate simulation. **Historical accuracy caveats** are explicit:
1895 is a famous Lumière milestone, not the first universal moving image;
Shree Pundalik vs Raja Harishchandra is a real early Indian film discussion;
and the Telugu “24 crafts” expression does **not** mean exactly 24 jobs on
every film or constitute a verified official federation roster.

## Compatibility and verification

- 14 newly authored three-stage stories with unique lesson-specific artwork
  per stage, plus the previous 19 visual-first experiences = 33/33.
- No lesson ID, answer, quiz completion route, local progress key, Telugu
  helper, original practice note, existing storyboard, gallery, download,
  backup JSON schema or native permission was changed.
- Offline; no account or paid media/API needed.
- New source test checks all 14 real lesson IDs, three complete steps, all
  illustration modes, storyboard interactions, claim qualifiers, no storage
  writes and preserved learning routes.
- Real compiled-site Chromium test opens all 14, advances 0→1→2, checks
  that the three SVG drawings change, reveals the explanation, opens
  original reading, verifies quiz/notes and returns to Home.
- Mobile Chromium QA tests every new lesson at 390px or 320px, checks
  horizontal overflow and captures screenshots.
- Full build and Android debug packaging must pass before source merge.

## Android test APK boundary

GitHub Android artifacts are debug builds signed with a **temporary signing
identity**; they cannot be assumed to update an existing installation.
The public managed preview stays v0.12A2 until persistent signing and
real-device backup/upgrade checks prove an update is safe. Do not remove
a previous installation containing valuable locally saved data merely
to test this build.
