# Frame One v0.13A16 — Quiet, professional, poster-first Home

## User-requested refinements

1. **Remove** the entire Android-only **"YOUR WORK STAYS ON THIS DEVICE"**
   Home announcement and its backup button. Also remove all associated
   Home-specific styling; do not simply hide it with CSS.
2. Keep the six authentic Netflix-style horizontal catalog shelves and
   original original-art poster navigation **above** all full interactive
   activities. Home now follows: original cinematic hero and optional
   personal frames → genuine journey resume when relevant → compact
   library intro / offline search → **six content rails** → optional
   interactive filmmaking workshops → filming practice → more destinations.
3. Turn the two large, visually distracting home workshops (Scene
   Anatomy and Direct the Moment) into a single, visually restrained
   **"Step behind the frame"** disclosure that is closed by default. Both
   actual interactive learning experiences still exist and operate after
   opening it, including their existing navigation/handoffs.
4. Leave **Film it yourself** as its existing compact card **after** all
   six shelves, because lesson-to-practice handoff must focus its matching
   exercise automatically, without a hidden ancestor.
5. Tighten vertical whitespace, provide consistent understated borders,
   dark surfaces, keyboard focus and mobile-friendly controls at 320px.

## Data and safety

This is **presentation-only**, not a data/schema change. All 33 lessons,
seven Labs, existing quizzes, progress, Telugu helpers, personal photos,
storyboards and original notes remain unchanged. The true Android native
backup/export panel in **Learn → Learning backup** still exists, including
its real file export/restore rules; removing a prominent Home advertisement
does NOT remove or weaken backups.

The temporarily signed debug APK may not install over an existing
Frame One application. This phase intentionally does not modify signing,
the public stable-preview channel, stored content or native permissions.
