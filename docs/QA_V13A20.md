# Frame One v0.13A20 — native Android read-only backup preflight acceptance

## Scope

Extend the already-passing v0.13A19 full Android emulator backup and restore
test to exercise the v0.13A18 learner-facing **Check a backup JSON file**
control in a real Android WebView and real system DocumentsUI picker.

After writing a genuine practice note, completing a lesson and creating an
actual Make Lab storyboard through the UI, CI exports the *original app-produced*
backup JSON via Capacitor Filesystem/Share. The test copies those bytes verbatim
to Android Downloads with ADB as a **simulated external save destination**,
clears the app's private data and verifies the empty 0/33 progress.

Before restoring anything, the test now:
1. Opens **Learn → Keep a copy of your learning**.
2. Taps **Check a backup JSON file** and chooses the *same actual exported
   file* from the Android system picker.
3. Requires the read-only **Checked: 1 completed lessons** and
   **Nothing was restored** messages, and checks there is no destructive
   restore confirmation.
4. Returns to Home and verifies progress is **still 0/33**.
5. Opens Learn again, independently taps **Restore a backup JSON file**,
   chooses the same external JSON, explicitly consents to overwrite and
   verifies 1/33 completed progress, the saved practice note and storyboard.

This catches accidental future changes that make inspection destructive
or skip the actual Android file-selection flow. Both paths reuse one
Android Downloads picker helper.

## Acceptance

- Source navigation contract checks distinguish read-only inspect from restore.
- The full Android API 35 system-picker CI must pass, including original
  Filesystem/Share export and real WebView UI checks.
- Other source, browser and Android QA suites must remain green.

## Boundaries

This is an Android **test-only** change. No app code, local storage keys,
private content, backup schema, curriculum, signing keys or APK release
workflow changed. Android CI simulates the save destination via ADB; this
is **not** a real user's external share-save proof. Persistent QA signing,
two independently signed build upgrades, physical-device backup and
install/upgrade acceptance remain unresolved release gates.

The public preview stays v0.12A2 until those release checks pass.
