# Frame One v0.9G — portable learning-backup fallback

Date: 27 October 2026. **Engineering test milestone, not a public release.**

## Goal

On Android, an ordinary browser download can behave differently inside a Capacitor WebView. Preserve a usable way to copy and restore locally saved lessons, practice notes and storyboards **without changing the existing v1 data schema or introducing any server**.

## Implementation

- Learn → **Keep a copy of your learning** retains the original JSON file download and file-import buttons.
- New collapsed **Download not working? Copy or paste a backup** section provides a user-initiated JSON text export and pasted JSON restore.
- The export text is generated by the original legacy `makeBackup()` function through a typed, read-only `getBackupJSON()` bridge. It includes `format: frameone-learning-backup`, `version: 1`, completed lessons, notes and storyboard.
- When the Clipboard API is available, **Show and copy backup text** tries to copy it. If blocked, the backup is visible in a readonly, select-all-on-focus text area so it can be manually copied. All text remains on the user's device.
- Restoring pasted text and restoring an uploaded JSON file share the same parser, 2 MB/character guard, explicit destructive confirmation, legacy schema validation, storage rollback protections and progress-refresh callback.
- Pasted private JSON is cleared after successful restore. The learner is warned not to post backups publicly; backups include authored notes.
- No new permissions, backend, remote service, account, telemetry or local-storage key changes.

## Remaining limitations

- Clipboard permissions/behavior and file picker need **real Android WebView tests**. The fallback textarea is intentionally usable even without Clipboard API access.
- JSON backup is sensitive because it includes local notes/storyboards: copy it into a private, durable location, not a public chat.
- The same device must still be tested for exports/imports after reinstalling; uninstalling an Android app normally removes locally stored data.
- GitHub debug APK signing may change between builds, so an in-place update is not guaranteed. Export and verify a backup before uninstall.
- Cloudflare production Worker URL, production deployment success, Android accessibility and iOS build are not yet verified.
