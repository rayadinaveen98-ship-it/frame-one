# Frame One — Learn the art of filmmaking

**Current checkpoint: v0.9B (27 October 2026).** Beginner-friendly, creative and interactive filmmaking education for web, Android and iOS.

The completed **prototype curriculum** contains 33 drafted lessons in 6 chapters, 7 creative labs, 47 film terms, 9 introductory roles, partial Telugu learning aids, quizzes, illustrated exercises and locally saved storyboards.

## Project status

- **Working browser prototype:** archived in [history/browser/](history/browser/); the most recent standalone preview is [preview/standalone.html](preview/standalone.html).
- **React + TypeScript + Vite + Capacitor v0.9B:** hybrid source migration assembled and source-level tests passed locally, but **production build, full React visual QA, Android APK and iOS build are NOT yet verified**.
- **Source handoff:** original complete v0.9B ZIP exists as a conversation artifact; uploading its full expanded codebase to this repository is a separate verification step. This checkpoint does not claim it has been uploaded.
- **Privacy and rights:** no backend, accounts, private user data or bundled unlicensed film scenes. No open-source license has been selected; public visibility alone does not grant reuse rights.
